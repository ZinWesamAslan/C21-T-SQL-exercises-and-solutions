# C21-T-SQL-exercises-and-solutions

This repository contains tests, quizzes, and practical challenges created during my study of the **ProgrammingAdvices.com T-SQL Course (Course 21)**. 

To reinforce my understanding, I leveraged AI to generate targeted questions and practical database exercises after each module.

---

## 📂 Repository Structure

### 01 Module Tests And Exercises
- **Module Quizzes:** Quizzes generated after completing each module to test key concepts.
- **Progressive Difficulty:**
  - **Early Modules:** Easy-to-medium questions designed to recall foundational SQL concepts learned in previous courses.
  - **Midterm Exam:** A comprehensive test covering all concepts taught in the first half of the course.
  - **Advanced Modules:** Harder, more complex queries and exercises.
- **Database Used:** `VehicleMakesDB`

### 02 Comprehensive Challenges
- **Custom Project:** A lightweight database designed for an educational institute (`InstituteDB`).
- **Final Practice:** Contains **20 practical and varied SQL questions/tasks** covering all concepts learned throughout the entire course.
- **Real-World Value:** Designed to reflect practical scenarios needed when building real-world applications that interact with an institute management database.

## 🛠 Database References
